# 考研数学题解入库规则

当用户提出“帮我把这题入库”或在聊天窗口粘贴考研数学题目时：
1. 必须按照 SOP 6 层架构（Layer 1~6）规范化整理（含微元间距、规范 LaTeX）。
2. 根据学科自动判断：
   - 微积分/极限/导数/积分等 -> 追加写入 `content/高等数学_题解集.md`
   - 矩阵/向量/特征值/线性方程组等 -> 追加写入 `content/线性代数_题解集.md`
3. 写入后必须自动执行终端命令：`npm run deploy`，实现全自动编译、目录索引更新与 GitHub Pages 部署。
4. 返回给用户线上直达链接：`https://xunyuefei.github.io/kaoyan-math/#problem-[题号]`。
