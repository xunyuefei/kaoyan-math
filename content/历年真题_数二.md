### 📌 题目 2005-T4：一阶线性非齐次微分方程初值求解
所属章节：`常微分方程` · 来源题集：`2005年数二`
题型标签：`🟠 计算失误` / `填空题(4分)` / `一阶线性微分方程` / `积分因子法` / `分部积分`

**原题呈现**：
微分方程 $x y' + 2y = x \ln x$ 满足 $y(1) = -\frac{1}{9}$ 的解为 ______。

> 💡 **核心突破手眼法**：
> **IF**: 看到含有 $x y' + 2y = f(x)$ 的一阶方程且已知 $x > 0$；
> **THEN**: 严禁直接套公式！第一步必须两边同除以 $x$ 归一化为标准型 $y' + \frac{2}{x}y = \ln x$；第二步提取积分因子 $\mu(x) = \mathrm{e}^{\int \frac{2}{x}\,\mathrm{d}x} = x^2$，将左边整体还原为导数 $(x^2 y)' = x^2 \ln x$；第三步分部积分求出通解，再代入初值 $y(1) = -\frac{1}{9}$ 锁定积分常数 $C = 0$。

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：一阶线性非齐次微分方程 $x y' + 2y = x \ln x$，伴随定点初始条件 $y(1) = -\frac{1}{9}$。
* **算子约束与定义域**：由于方程包含对数项 $\ln x$，定义域隐式锁定为 $x \in (0, +\infty)$。方程导数最高阶数为 1 阶，$y$ 与 $y'$ 均为一次幂。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **微分逆运算与积分因子语义**：
  * 左端形式 $x y' + 2y$ 极度接近乘积导数。两端同乘以 $x$ 得到 $x^2 y' + 2xy = \frac{\mathrm{d}}{\mathrm{d}x}(x^2 y)$。
  * 乘积求导逆过程直接规避了复杂公式记忆，将微分方程的“求导求解”本质还原为“不定积分还原”。
* **初始条件锚定语义**：平面曲线族在 $(1, -\frac{1}{9})$ 处有且仅有一条积分曲线穿过，确定唯一特解。

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“一阶线性微分方程的标准型与通解公式” 联立 “定解条件的代入与特解提取”（对接武忠祥《高等数学辅导讲义》常微分方程章节一阶方程核心题型）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【标准型归一化锁】** | $x y' + 2y = x \ln x$ | 首项系数必须为 1 才能套用 $P(x), Q(x)$ 体系 | $y' + \frac{2}{x}y = \ln x$ |
| **【积分因子复原锁】** | $P(x) = \frac{2}{x}$ | 乘积导数还原法 $\mu(x) = \mathrm{e}^{\int \frac{2}{x}\,\mathrm{d}x} = x^2$ | $\frac{\mathrm{d}}{\mathrm{d}x}(x^2 y) = x^2 \ln x$ |
| **【初值特解锚定锁】** | $y(1) = -\frac{1}{9}$ | 代入点值消除自由度 $C$ | 确定常数 $C = 0$ 锁定唯一特解 |

* **4.2 错因深度复盘（🟠 计算失误剖析）**：
  * **失误点一（未归一化）**：直接把原式中的 $2$ 当作 $P(x)$、$x\ln x$ 当作 $Q(x)$ 代入通解公式，导致积分因子错算为 $\mathrm{e}^{2x}$，全盘皆输；
  * **失误点二（分部积分符号手滑）**：在计算 $\int x^2 \ln x\,\mathrm{d}x = \frac{1}{3}x^3 \ln x - \frac{1}{3}\int x^2\,\mathrm{d}x$ 时，后半段常数因子 $\frac{1}{3} \times \frac{1}{3} = \frac{1}{9}$ 漏乘或负号弄错；
  * **失误点三（积分常数漏除）**：将通解写成 $y = \frac{1}{3}x\ln x - \frac{1}{9}x + C$，忘记常数 $C$ 同样处于括号内部，必须除以积分因子 $x^2$（即 $\frac{C}{x^2}$）。

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **方程标准化**：
  两端同除以 $x$（$x > 0$）：
  $$y' + \frac{2}{x}y = \ln x$$
  此时 $P(x) = \frac{2}{x}$，$Q(x) = \ln x$。

* **求积分因子与通解**：
  $$\mu(x) = \mathrm{e}^{\int \frac{2}{x}\,\mathrm{d}x} = \mathrm{e}^{2\ln x} = x^2$$
  两端同乘以 $x^2$ 得：
  $$(x^2 y)' = x^2 \ln x$$
  两端积分：
  $$x^2 y = \int x^2 \ln x \, \mathrm{d}x = \frac{1}{3} \int \ln x \, \mathrm{d}(x^3) = \frac{1}{3} x^3 \ln x - \frac{1}{3} \int x^3 \cdot \frac{1}{x} \, \mathrm{d}x = \frac{1}{3} x^3 \ln x - \frac{1}{9} x^3 + C$$
  由此解得通解为：
  $$y = \frac{1}{3} x \ln x - \frac{1}{9} x + \frac{C}{x^2}$$

* **代入初始条件确定特解**：
  由 $y(1) = -\frac{1}{9}$，代入 $x=1$：
  $$-\frac{1}{9} = \frac{1}{3}(1)\ln 1 - \frac{1}{9}(1) + \frac{C}{1^2} = 0 - \frac{1}{9} + C \implies C = 0$$
  因此方程满足初值条件的特解为：
  $$y = \frac{1}{3} x \ln x - \frac{1}{9} x$$

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：
  * **防线一**：见到 $y'$ 带有变系数 $x$ 时，先深呼吸确认是否已经除干净。
  * **防线二**：特解写完后务必心算回代：$y(1) = -\frac{1}{9}$ 吻合；$y' = \frac{1}{3}\ln x + \frac{1}{3} - \frac{1}{9} = \frac{1}{3}\ln x + \frac{2}{9}$，则 $xy' + 2y = \frac{1}{3}x\ln x + \frac{2}{9}x + \frac{2}{3}x\ln x - \frac{2}{9}x = x\ln x$，检验 100% 正确！
* **延伸变式**：若右端为非齐次高阶或伯努利形式如 $x y' + 2y = x^2 y^2 \ln x$，则需两边同除以 $y^2$ 并令 $z = y^{-1}$ 转化为一阶线性方程求解。

🎯 **最终正确答案**：
$$
y = \frac{1}{3} x \ln x - \frac{1}{9} x
$$

### 📌 题目 2005-T11：二元复合与变限积分的二阶偏导同构（波动方程）
所属章节：`多元函数微分` · 来源题集：`2005年数二`
题型标签：`🔴 无思路` / `单项选择题(4分)` / `多元复合求导` / `变限积分求导` / `一维波动方程解同构`

**原题呈现**：
设函数 $u(x,y) = \varphi(x+y)+\varphi(x-y)+\int_{x-y}^{x+y} \psi(t)\,\mathrm{d}t$，其中 $\varphi$ 具有二阶导数，$\psi$ 具有一阶导数，则必有（ ）  
(A) $\frac{\partial^2 u}{\partial x^2} = -\frac{\partial^2 u}{\partial y^2}$ $\quad$ (B) $\frac{\partial^2 u}{\partial x^2} = \frac{\partial^2 u}{\partial y^2}$ $\quad$ (C) $\frac{\partial^2 u}{\partial x \partial y} = \frac{\partial^2 u}{\partial y^2}$ $\quad$ (D) $\frac{\partial^2 u}{\partial x \partial y} = \frac{\partial^2 u}{\partial x^2}$

> 💡 **核心突破手眼法**：
> **IF**: 看到 $u(x,y) = \varphi(x+y) + \varphi(x-y) + \int_{x-y}^{x+y} \psi(t)\,\mathrm{d}t$；  
> **THEN**: 秒杀眼法：这是极度经典的一维波动方程达朗贝尔（D'Alembert）公式原型！波速 $a=1$，波动方程形式即为 $u_{tt} = a^2 u_{xx} \iff u_{yy} = u_{xx}$，直接锁定选项 (B)！演算眼法：变限下限为 $x-y$，对 $y$ 一阶求导产生负号 $-1$，二阶求导链式法则再次产生负号 $(-1) \times (-1) = 1$，负号完全抵消，使得 $u_{yy}$ 的各项系数与 $u_{xx}$ 严格一致。

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：含有复合自变量 $x+y, x-y$ 的抽象未知函数 $\varphi$ 与上下限均为二元线性的变限积分 $\int_{x-y}^{x+y} \psi(t)\,\mathrm{d}t$。
* **求导目标**：判断各二阶偏导数（$u_{xx}, u_{yy}, u_{xy}$）之间的代数等量关系。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **物理同构（一维齐次波动方程）**：
  * 在数理方程中，一维波动方程 $\frac{\partial^2 u}{\partial t^2} = a^2 \frac{\partial^2 u}{\partial x^2}$ 在初值条件 $u|_{t=0} = f(x), u_t|_{t=0} = g(x)$ 下的达朗贝尔公式解恰为 $u(x,t) = \frac{f(x+at)+f(x-at)}{2} + \frac{1}{2a}\int_{x-at}^{x+at} g(s)\,\mathrm{d}s$。
  * 本题中将时间变量 $t$ 置换为 $y$，波速 $a = 1$，函数结构与达朗贝尔解完全同构，法理上必然满足 $\frac{\partial^2 u}{\partial x^2} = \frac{\partial^2 u}{\partial y^2}$。
* **微积分链式法则对消语义**：
  * 对 $x$ 求导：下限 $x-y$ 对 $x$ 导数为 $1$；
  * 对 $y$ 求导：下限 $x-y$ 对 $y$ 导数为 $-1$。一阶求导时下限项为 $-\psi(x-y)\cdot(-1) = +\psi(x-y)$。对 $y$ 二阶求导时，$\psi(x-y)$ 再次产生外层负号，变回 $-\psi'(x-y)$，与 $u_{xx}$ 完全重合。

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“多元复合抽象函数二阶偏导数” 联立 “莱布尼茨变限积分求导公式”（对接武忠祥《高等数学辅导讲义》第八章多元函数微分学高频考点）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【一阶偏导解耦锁】** | $u(x,y)$ 包含 $\varphi(x\pm y)$ 与 $\int_{x-y}^{x+y}\psi(t)\,\mathrm{d}t$ | 链式法则与 Leibniz 变限积分求导 | $u_x = \varphi'(x+y)+\varphi'(x-y)+\psi(x+y)-\psi(x-y)$ |
| **【二阶偏导同构锁】** | $u_y$ 下限二次负号相乘抵消 | $\frac{\partial}{\partial y}[\psi(x-y)] = -\psi'(x-y)$ | $\frac{\partial^2 u}{\partial x^2} = \frac{\partial^2 u}{\partial y^2}$ |

* **4.2 错因深度复盘（🔴 无思路破局）**：
  * 考场遇到这道题产生“无思路”，核心盲点在于：面对变限积分与抽象复合函数的叠加，心理上被冗长的符号震慑，不敢动笔求导；或者对变限积分下限求导法则 $\frac{\partial}{\partial y}\int_{v(y)}^{u(y)} f(t)\,\mathrm{d}t = f(u)u'_y - f(v)v'_y$ 中的负号心存疑虑。
  * 牢记：只要按部就班算出 $u_x, u_y, u_{xx}, u_{yy}$，两行推导即可浮现等价真相。

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **求一阶偏导数**：
  对 $x$ 求偏导：
  $$u_x = \varphi'(x+y)\cdot 1 + \varphi'(x-y)\cdot 1 + \psi(x+y)\cdot 1 - \psi(x-y)\cdot 1 = \varphi'(x+y) + \varphi'(x-y) + \psi(x+y) - \psi(x-y)$$
  对 $y$ 求偏导：
  $$u_y = \varphi'(x+y)\cdot 1 + \varphi'(x-y)\cdot(-1) + \psi(x+y)\cdot 1 - \psi(x-y)\cdot(-1) = \varphi'(x+y) - \varphi'(x-y) + \psi(x+y) + \psi(x-y)$$

* **求二阶偏导数**：
  对 $u_x$ 再次关于 $x$ 求偏导：
  $$u_{xx} = \varphi''(x+y)\cdot 1 + \varphi''(x-y)\cdot 1 + \psi'(x+y)\cdot 1 - \psi'(x-y)\cdot 1 = \varphi''(x+y) + \varphi''(x-y) + \psi'(x+y) - \psi'(x-y)$$
  对 $u_y$ 再次关于 $y$ 求偏导：
  $$u_{yy} = \varphi''(x+y)\cdot 1 - \varphi''(x-y)\cdot(-1) + \psi'(x+y)\cdot 1 + \psi'(x-y)\cdot(-1) = \varphi''(x+y) + \varphi''(x-y) + \psi'(x+y) - \psi'(x-y)$$

* **对比结论**：
  $$u_{xx} = u_{yy} \iff \frac{\partial^2 u}{\partial x^2} = \frac{\partial^2 u}{\partial y^2}$$

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：注意选项 (C) 和 (D) 涉及混合偏导 $u_{xy}$。我们计算 $u_{xy} = \varphi''(x+y) - \varphi''(x-y) + \psi'(x+y) + \psi'(x-y)$，由于 $\varphi''$ 中间为减号，它既不恒等于 $u_{xx}$ 也不恒等于 $u_{yy}$，切勿臆测混合偏导相等。
* **延伸变式**：若题干将自变量改为 $x+2y$ 与 $x-2y$，则二阶导数将提系数 $2^2 = 4$，此时关系式升维变为 $\frac{\partial^2 u}{\partial y^2} = 4\frac{\partial^2 u}{\partial x^2}$。

🎯 **最终正确答案**：
$$
\mathbf{(B)}
$$

### 📌 题目 2005-T14：可逆矩阵初等变换对伴随矩阵的映射规律
所属章节：`矩阵` · 来源题集：`2005年数二`
题型标签：`🔴 无思路` / `单项选择题(4分)` / `伴随矩阵性质` / `初等行变换与列变换` / `矩阵求逆与转置`

**原题呈现**：
设 $A$ 为 $n (n \geqslant 2)$ 阶可逆矩阵，交换 $A$ 的第 1 行与第 2 行得矩阵 $B$，$A^*, B^*$ 分别为 $A, B$ 的伴随矩阵，则（ ）  
(A) 交换 $A^*$ 的第 1 列与第 2 列得 $B^*$  
(B) 交换 $A^*$ 的第 1 行与第 2 行得 $B^*$  
(C) 交换 $A^*$ 的第 1 列与第 2 列得 $-B^*$  
(D) 交换 $A^*$ 的第 1 行与第 2 行得 $-B^*$

> 💡 **核心突破手眼法**：
> **IF**: 看到原矩阵做初等变换，考察伴随矩阵的变换规律；  
> **THEN**: 伴随矩阵的核心代数万能钥匙是 $M^* = |M| M^{-1}$！初等行变换对应左乘初等矩阵 $B = E_{12} A$。求逆后位置自动颠倒：$(E_{12} A)^{-1} = A^{-1} E_{12}^{-1} = A^{-1} E_{12}$（左乘变右乘，行变换变列变换）；再乘行列式 $|B| = -|A|$ 贡献负号，立刻得出 $B^* = - A^* E_{12}$，即对 $A^*$ 交换第 1、2 列等于 $-B^*$（选 C）！

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：可逆矩阵 $A$ 经初等行变换（置换阵 $E_{12}$ 左乘）得到 $B = E_{12} A$，研究伴随映射 $A \mapsto A^*$ 与 $B \mapsto B^*$ 之间的矩阵初等变换关系。
* **选项特征**：涉及伴随矩阵的“行交换”还是“列交换”，以及是否存在符号反转（$\pm B^*$）。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **伴随定义与初等变换位置反转语义**：
  * 伴随矩阵 $A^* = (A_{ij})^{\mathrm{T}}$ 本身自带转置操作，行与列天然互换；
  * 代数求逆公式中 $(P Q)^{-1} = Q^{-1} P^{-1}$ 具有天然的“后进先出”位置颠倒性。原矩阵上的左乘行变换，取逆后必然转移至右侧变为对逆矩阵的列变换。
* **行列式奇偶置换保号语义**：交换两行导致行列式变号，即 $|E_{12}| = -1$。

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“伴随矩阵代数性质 $A^* = |A|A^{-1}$” 联立 “初等矩阵乘法与行列式变换法则”（对接李永乐《线性代数辅导讲义》第一章与第二章矩阵代数考点）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【初等矩阵代数锁】** | 交换 $A$ 的第 1、2 行得到 $B$ | 初等置换矩阵 $B = E_{12} A$，且 $E_{12}^{-1} = E_{12}$ | $|E_{12}| = -1$ |
| **【伴随求逆位置锁】** | $B^* = |B| B^{-1}$ | $(E_{12}A)^{-1} = A^{-1} E_{12}^{-1}$ | $B^* = -A^* E_{12}$ |

* **4.2 错因深度复盘（🔴 无思路破局）**：
  * 产生“无思路”的根源：试图用代数余子式的定义式 $A^* = \begin{pmatrix} A_{11} & A_{21} & \cdots \\ A_{12} & A_{22} & \cdots \end{pmatrix}$ 逐项分析，但划去某行某列后的余子式符号和位置错综复杂，导致思维过载中断。
  * 破局心法：**只要矩阵可逆，伴随矩阵的分析必须无条件升维至 $A^* = |A|A^{-1}$！** 将离散的元素分析转化为连续的整矩阵乘法。

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **初等矩阵表述**：
  设 $E_{12}$ 为交换第 1、2 行的 $n$ 阶初等矩阵。则：
  $$B = E_{12} A$$
  已知初等置换矩阵具有性质：$E_{12}^{-1} = E_{12}$，且 $|E_{12}| = -1$。

* **利用公式展开 $B^*$**：
  根据可逆矩阵伴随公式 $M^* = |M| M^{-1}$：
  $$B^* = |B| B^{-1} = |E_{12} A| (E_{12} A)^{-1}$$
  利用行列式乘法公式与矩阵求逆反序律：
  $$|E_{12} A| = |E_{12}| |A| = -|A|$$
  $$(E_{12} A)^{-1} = A^{-1} E_{12}^{-1} = A^{-1} E_{12}$$
  代入合并得：
  $$B^* = -|A| A^{-1} E_{12} = - (|A| A^{-1}) E_{12} = - A^* E_{12}$$
  两边同乘以 $-1$：
  $$A^* E_{12} = -B^*$$

* **几何与操作含义诠释**：
  矩阵 $A^*$ 右乘初等矩阵 $E_{12}$，其算子含义恰好为“将矩阵 $A^*$ 的第 1 列与第 2 列互换”。
  因此，交换 $A^*$ 的第 1 列与第 2 列后得到的矩阵为 $-B^*$。

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：
  * **防线一**：选项 (A) 与 (C) 区分在负号上。很多同学能猜到“行变列”，但忽略了交换行导致行列式变号 $|B| = -|A|$，误选 (A)；
  * **防线二**：选项 (B) 错在将左乘行变换依然看作行变换，混淆了转置与求逆的列映射。
* **延伸变式**：若原题改为“将 $A$ 的第 1 行乘以常数 $k \neq 0$ 得到 $B$”，则 $B = E_1(k) A$，$|B| = k|A|$，$B^{-1} = A^{-1} E_1(k^{-1})$，则 $B^* = k|A| A^{-1} E_1(\frac{1}{k}) = A^* \operatorname{diag}(1, k, k, \dots, k)$，对应将 $A^*$ 的其余列乘以 $k$！

🎯 **最终正确答案**：
$$
\mathbf{(C)}
$$

### 📌 题目 2005-T19：连续可导函数构造辅助函数证明零点与导数乘积
所属章节：`一元函数微分` · 来源题集：`2005年数二`
题型标签：`🔴 无思路` / `解答题(10分)` / `辅助函数构造` / `零点存在定理` / `拉格朗日中值定理`

**原题呈现**：
已知函数 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0, f(1)=1$。证明：  
（1）存在 $\xi \in (0,1)$，使得 $f(\xi) = 1-\xi$；  
（2）存在两个不同的点 $\eta, \zeta \in (0,1)$，使得 $f'(\eta) f'(\zeta) = 1$。

> 💡 **核心突破手眼法（直击学员思考反馈）**：
> **学员思考反馈**：“这个第一问--我想的是构造辅助函数”  
> **导师深度解答**：你的想法完全正确且是最标准的考场破局第一反射！  
> **IF**: 看到要证的方程 $f(\xi) = 1 - \xi$ 既含有自变量又含有函数值，且**不含导数项**；  
> **THEN**: 考场直接启动“移项齐次化”：$f(\xi) + \xi - 1 = 0 \iff$ 构造辅助函数 $F(x) = f(x) + x - 1$。验证闭区间端点 $F(0) = -1 < 0$ 与 $F(1) = 1 > 0$，因 $F(0)F(1) < 0$ 且连续，直接触发零点存在定理锁定 $\xi \in (0,1)$！  
> **升维连接第（2）问**：看到求证导数积 $f'(\eta)f'(\zeta) = 1$，以第一问的 $\xi$ 为断点将 $[0,1]$ 分割为 $[0, \xi]$ 与 $[\xi, 1]$，分别启动拉格朗日中值定理，代入第一问结论 $f(\xi) = 1-\xi$ 瞬间完成分子分母镜像对消！

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：满足连续可导基本分析性质的实函数，已知区间边界点值 $f(0)=0, f(1)=1$。
* **待证结构**：
  * 第（1）问：非导数实数方程 $f(\xi) = 1 - \xi$ 的内点存在性；
  * 第（2）问：导数乘积结构 $f'(\eta) f'(\zeta) = 1$ 的双内点存在性。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **几何直观语义**：
  * 直线 $y = 1 - x$ 连接 $(0, 1)$ 与 $(1, 0)$；曲线 $y = f(x)$ 从 $(0, 0)$ 走向 $(1, 1)$。
  * 平面上两条连续曲线分别连接正方形对角线的两对端点，它们在正方形内部必然发生交截！交点的横坐标即为 $\xi$。
* **中值定理分割对消语义**：
  * 割线斜率 $k_1 = \frac{f(\xi)-0}{\xi-0} = \frac{1-\xi}{\xi}$；
  * 割线斜率 $k_2 = \frac{1-f(\xi)}{1-\xi} = \frac{1-(1-\xi)}{1-\xi} = \frac{\xi}{1-\xi}$；
  * 观察发现 $k_1 \cdot k_2 = \frac{1-\xi}{\xi} \cdot \frac{\xi}{1-\xi} \equiv 1$！由拉格朗日中值定理，导数值恰好能精准命中这两个互为倒数的割线斜率。

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“零点存在定理（介值定理）与辅助函数构造” 联立 “拉格朗日中值定理分段应用”（对接武忠祥《高等数学辅导讲义》中值定理与零点问题章节核心题型）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【目标移项零点锁】** | 证明 $f(\xi) = 1 - \xi$ | 移项构造齐次式 $f(x) + x - 1 = 0$ | 设辅助函数 $F(x) = f(x) + x - 1$ |
| **【端点异号存在锁】** | $F(0) = -1 < 0, F(1) = 1 > 0$ | 连续函数在闭区间端点严格异号 | 零点存在定理：$\exists \xi \in (0,1), F(\xi)=0$ |
| **【双点导数对消锁】** | 证明 $f'(\eta)f'(\zeta) = 1$ | 引入第一问交点 $\xi$ 分割区间 | 在 $[0, \xi]$ 与 $[\xi, 1]$ 启动拉格朗日定理 |

* **4.2 错因深度复盘（🔴 无思路破局）**：
  * 第（1）问如果产生卡顿，往往是误以为出现 $\xi$ 就必须用罗尔定理或拉格朗日定理，到处寻找原函数求导，走入死胡同；
  * 牢记铁律：**式子中只要没有导数符号 $f'$，100% 优先考虑零点存在定理与介值定理！**

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **证明第（1）问**：
  设辅助函数：
  $$F(x) = f(x) + x - 1$$
  因为 $f(x)$ 在 $[0,1]$ 上连续，且 $x-1$ 为初等连续函数，所以 $F(x)$ 在 $[0,1]$ 上连续。
  代入区间端点计算：
  $$F(0) = f(0) + 0 - 1 = 0 - 1 = -1 < 0$$
  $$F(1) = f(1) + 1 - 1 = 1 + 0 = 1 > 0$$
  由于 $F(0) \cdot F(1) = -1 < 0$，根据闭区间连续函数的零点存在定理，必存在 $\xi \in (0,1)$，使得：
  $$F(\xi) = 0 \implies f(\xi) + \xi - 1 = 0 \implies f(\xi) = 1 - \xi$$
  第（1）问得证。

* **证明第（2）问（升维推导）**：
  由第（1）问已知，存在 $\xi \in (0, 1)$ 使得 $f(\xi) = 1 - \xi$。
  在区间 $[0, \xi]$ 上，$f(x)$ 满足在 $[0, \xi]$ 上连续，在 $(0, \xi)$ 内可导，由拉格朗日中值定理，存在 $\eta \in (0, \xi)$，使得：
  $$f'(\eta) = \frac{f(\xi) - f(0)}{\xi - 0} = \frac{f(\xi)}{\xi}$$
  在区间 $[\xi, 1]$ 上，$f(x)$ 满足在 $[\xi, 1]$ 上连续，在 $(\xi, 1)$ 内可导，由拉格朗日中值定理，存在 $\zeta \in (\xi, 1)$，使得：
  $$f'(\zeta) = \frac{f(1) - f(\xi)}{1 - \xi} = \frac{1 - f(\xi)}{1 - \xi}$$
  两式相乘，并将 $f(\xi) = 1 - \xi$ 代入：
  $$f'(\eta) f'(\zeta) = \frac{f(\xi)}{\xi} \cdot \frac{1 - f(\xi)}{1 - \xi} = \frac{1 - \xi}{\xi} \cdot \frac{1 - (1 - \xi)}{1 - \xi} = \frac{1 - \xi}{\xi} \cdot \frac{\xi}{1 - \xi} = 1$$
  由于 $\eta \in (0, \xi)$ 且 $\zeta \in (\xi, 1)$，显然 $\eta \neq \zeta$ 且均在 $(0,1)$ 内。
  第（2）问得证。

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：
  * **防线一**：开闭区间判定！端点值严格小于 0 与大于 0，才能保证 $\xi \in (0, 1)$ 开区间内；若端点为 0 则可能退化在边界上；
  * **防线二**：第（2）问中强调“两个不同点”，通过分段区间 $(0, \xi)$ 与 $(\xi, 1)$ 天然不相交保证 $\eta < \xi < \zeta$，严谨度拉满。
* **延伸变式**：若结论改为证明 $f'(\eta) + f'(\zeta) = 2$ 或倒数和形式，同样利用割线斜率的调和/算术中值代数恒等变形获解。

🎯 **最终正确答案**：
$$
\text{（1）及（2）均严格获证。}
$$

### 📌 题目 2005-T22：向量组单向线性表示的秩与矛盾解校验
所属章节：`n维向量` · 来源题集：`2005年数二`
题型标签：`🔵 产生疑问` / `解答题(9分)` / `向量组单向线性表示` / `矩阵的秩` / `非齐次线性方程组相容性`

**原题呈现**：
确定常数 $a$，使向量组 $\alpha_1 = (1,1,a)^{\mathrm{T}}, \alpha_2 = (1,a,1)^{\mathrm{T}}, \alpha_3 = (a,1,1)^{\mathrm{T}}$ 可由向量组 $\beta_1 = (1,1,a)^{\mathrm{T}}, \beta_2 = (-2,a,4)^{\mathrm{T}}, \beta_3 = (-2,a,a)^{\mathrm{T}}$ 线性表示，但向量组 $\beta_1, \beta_2, \beta_3$ 不能由向量组 $\alpha_1, \alpha_2, \alpha_3$ 线性表示。

> 💡 **核心突破手眼法（直击学员思考反馈）**：
> **学员思考反馈**：“我想的是只要 $A$ 的秩比 $B$ 的秩小就可以，但我没有确定 $a$ 最终结果”  
> **导师深度解答**：你的直觉非常准！“$r(A) < r(B)$”确实是两个 3 维向量组单向线性表示的必要条件！之所以卡在锁定最终 $a$，是因为：  
> ① **第一道锁（单向性）**：$\beta$ 不能由 $\alpha$ 表示 $\implies r(A) < 3 \iff |A| = 0$，解出两个候选参数 $a = 1$ 和 $a = -2$；  
> ② **第二道锁（正向表示的相容性校验，漏掉此步将功亏一篑）**：必须检验 $\alpha$ 是否真能由 $\beta$ 表示！当 $a=-2$ 时，$B$ 的前两行完全相同，但 $\alpha_2 = (1, -2, 1)^{\mathrm{T}}$ 的前两个分量 $1 \neq -2$，增广矩阵无解（$r(B) \neq r(B, \alpha_2)$）！这直接摧毁了已知条件，故 $a=-2$ 产生矛盾被无情淘汰，最终唯一锁定 $a = 1$！

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：构造矩阵 $A = (\alpha_1, \alpha_2, \alpha_3)$ 与 $B = (\beta_1, \beta_2, \beta_3)$，其中元素含有待定参数 $a$。
* **单向表示约束**：
  * 条件 I：$A$ 的列可由 $B$ 的列线性表示 $\implies r(B) = r(B, A)$ 且 $r(A) \leqslant r(B)$；
  * 条件 II：$B$ 的列不能由 $A$ 的列线性表示 $\implies r(A, B) > r(A)$。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **空间维数与基的生成空间语义**：
  * 若 $r(A) = 3$，则 $\alpha_1, \alpha_2, \alpha_3$ 构成全空间 $\mathbb{R}^3$ 的一组基，全空间的基能线性表示三维空间中的任何向量（包含 $\beta_i$），这与“$\beta$ 不能由 $\alpha$ 表示”直接矛盾！
  * 因此，$A$ 必须退化，不能充满整个空间，即必须有 $|A| = 0$。
* **子空间包含关系语义**：
  * $a=1$ 时：$A$ 生成一维直线（$r(A)=1$），$B$ 生成全空间（$r(B)=3$），直线显然落在全空间内，单向表示成立；
  * $a=-2$ 时：$B$ 生成的空间中所有向量前两个分量必相等，但 $\alpha_2$ 前两个分量不相等，几何上 $\alpha_2$ 飞出了 $B$ 的生成子空间，正向表示破裂！

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“向量组的线性表示与等价充要条件” 联立 “矩阵的秩与非齐次线性方程组有解判别法”（对接李永乐《线性代数辅导讲义》第三章向量组核心题型）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【满秩排他锁】** | $\beta$ 不能由 $\alpha$ 线性表示 | 若 $r(A)=3$ 则张成整个 $\mathbb{R}^3$（矛盾） | 必有 $\|A\|=0 \implies a=1$ 或 $a=-2$ |
| **【候选值相容检验锁】** | $\alpha$ 必须能由 $\beta$ 线性表示 | 检验线性方程组 $Bx = \alpha_i$ 是否相容 | $a=-2$ 时增广阵无解淘汰；$a=1$ 完美成立 |

* **4.2 错因深度复盘（🔵 产生疑问破局）**：
  * 学员常产生的疑惑：“为什么只比秩的大小不够？”
  * 法理解释：**秩的大小不等只是向量空间维度的宏观包含必要条件，不是微观包含的充要条件！** 哪怕二维平面维数小于三维空间，但如果那是两个不同方向的子空间，微观向量依然可能不在其内。因此，必须逐一代入候选参数执行增广矩阵相容性校验。

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **由单向性推导候选参数**：
  若 $|A| \neq 0$，则 $r(A) = 3$。$\alpha_1, \alpha_2, \alpha_3$ 线性无关，构成 $\mathbb{R}^3$ 的一组基。
  此时 $\mathbb{R}^3$ 中任意向量均可由 $\alpha_1, \alpha_2, \alpha_3$ 线性表示，与“$\beta_1, \beta_2, \beta_3$ 不能由 $\alpha_1, \alpha_2, \alpha_3$ 线性表示”矛盾。
  故必须有：
  $$|A| = 0$$

* **计算行列式 $|A|$**：
  $$|A| = \begin{vmatrix} 1 & 1 & a \\ 1 & a & 1 \\ a & 1 & 1 \end{vmatrix}$$
  各行加到第一行：
  $$|A| = (a+2) \begin{vmatrix} 1 & 1 & 1 \\ 1 & a & 1 \\ a & 1 & 1 \end{vmatrix} \xlongequal{\substack{r_2-r_1 \\ r_3-r_1}} (a+2) \begin{vmatrix} 1 & 1 & 1 \\ 0 & a-1 & 0 \\ a-1 & 0 & 0 \end{vmatrix} = -(a+2)(a-1)^2 = 0$$
  解得候选值为：
  $$a = 1 \quad \text{或} \quad a = -2$$

* **分类代入校验**：
  * **情况 1：当 $a = 1$ 时**
    $$\alpha_1 = \alpha_2 = \alpha_3 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}, \quad r(A) = 1$$
    $$\beta_1 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}, \quad \beta_2 = \begin{pmatrix} -2 \\ 1 \\ 4 \end{pmatrix}, \quad \beta_3 = \begin{pmatrix} -2 \\ 1 \\ 1 \end{pmatrix}$$
    显然 $\alpha_1 = \alpha_2 = \alpha_3 = \beta_1$，故 $\alpha$ 组可由 $\beta$ 组线性表示。
    计算 $B$ 的行列式：
    $$|B| = \begin{vmatrix} 1 & -2 & -2 \\ 1 & 1 & 1 \\ 1 & 4 & 1 \end{vmatrix} \xlongequal{\substack{r_2-r_1 \\ r_3-r_1}} \begin{vmatrix} 1 & -2 & -2 \\ 0 & 3 & 3 \\ 0 & 6 & 3 \end{vmatrix} = 3 \times 3 - 3 \times 6 = -9 \neq 0$$
    故 $r(B) = 3$。由于 $r(B) = 3 > r(A) = 1$，$\beta$ 组不可能由 $\alpha$ 组线性表示。
    因此 $a = 1$ 符合题设全部要求！

  * **情况 2：当 $a = -2$ 时**
    此时 $\alpha_2 = \begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix}$，且：
    $$B = (\beta_1, \beta_2, \beta_3) = \begin{pmatrix} 1 & -2 & -2 \\ 1 & -2 & -2 \\ -2 & 4 & -2 \end{pmatrix}$$
    考察方程组 $B x = \alpha_2$ 的增广矩阵 $(B \vdots \alpha_2)$：
    $$(B \vdots \alpha_2) = \begin{pmatrix} 1 & -2 & -2 & \vdots & 1 \\ 1 & -2 & -2 & \vdots & -2 \\ -2 & 4 & -2 & \vdots & 1 \end{pmatrix} \xrightarrow{r_2 - r_1} \begin{pmatrix} 1 & -2 & -2 & \vdots & 1 \\ 0 & 0 & 0 & \vdots & -3 \\ -2 & 4 & -2 & \vdots & 1 \end{pmatrix}$$
    第二行出现 $[0, 0, 0 \vdots -3]$，说明 $r(B) = 2 \neq r(B \vdots \alpha_2) = 3$，非齐次方程组无解！
    即 $\alpha_2$ 根本不能由 $\beta_1, \beta_2, \beta_3$ 线性表示，与题设矛盾！故 $a = -2$ 必须舍去。

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：
  * **防线一**：只写 $|A|=0$ 得到 $a=1$ 或 $-2$，没有做相容性检验，痛失一半分值；
  * **防线二**：检验相容性时，若 $a=1$ 只验了 $\beta_1$，还要确认 $r(B) > r(A)$ 阻断反向表示。
* **延伸变式**：若题设改为“两个向量组等价”，则需要 $r(A) = r(B) = r(A, B)$，参数将由等价方程组完全确定。

🎯 **最终正确答案**：
$$
a = 1
$$

### 📌 题目 2005-T23：$AB=O$ 解空间维数与首行非零方程基础解系
所属章节：`线性方程组` · 来源题集：`2005年数二`
题型标签：`🔴 无思路` / `解答题(9分)` / `矩阵方程AB=O` / `解空间维数` / `Sylvester秩不等式` / `齐次线性方程组通解`

**原题呈现**：
已知 3 阶矩阵 $A$ 的第一行是 $(a,b,c)$，$a,b,c$ 不全为零，矩阵 $B = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 3 & 6 & k \end{pmatrix}$（$k$ 为常数），且 $AB = O$，求线性方程组 $Ax = 0$ 的通解。

> 💡 **核心突破手眼法（彻底消除心理排斥感）**：
> **学员心理阻抗深度剖析**：“这一题是看不懂--我只能联想到利用 $AB=O$ 推出秩的关系，但是‘矩阵 $A$ 的第一行是 $(a,b,c),a,b,c$ 不全为零’这句话我有点很排斥，因为只给了第一行，我就会想第二行第三行呢？”  
> **导师深度破局（法理祛魅）**：
> 考官只给你第一行，完全不是在“隐瞒条件”，而是送给你的**最强降维礼物**！  
> 1. **宏观锁定秩的下界**：“第一行不全为零”在代数语言中只有唯一目的——宣告 $A \neq O$！封死零矩阵，确立 $r(A) \geqslant 1$；  
> 2. **微观方程同解退化**：由 $AB=O \implies r(A) + r(B) \leqslant 3$。当分类讨论发现 $r(A)=1$ 时，根据矩阵秩为 1 的几何本质，$A$ 的第二行、第三行必然全部是第一行的常数倍！此时整个方程组 $Ax=0$ 在逻辑上同解退化为单行平面方程：$ax_1 + bx_2 + cx_3 = 0$！考官给你第一行，就是直接把这个单方程送到了你嘴边，第二行、第三行长什么样根本没有任何影响！

#### 第一步：Layer 1 代数表征（识别考卷符号）
* **特定代数表征结构**：矩阵方程乘积为零 $AB = O$，其中 $B$ 含有未知参数 $k$，$A$ 仅给出首行非零向量 $(a,b,c)$。
* **求解目标**：求齐次线性方程组 $Ax = 0$ 的通解，解的形态依赖参数 $k$ 的分类讨论。

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
* **$AB=O$ 与解空间正交/包含语义**：
  * $A B = A (\beta_1, \beta_2, \beta_3) = (A\beta_1, A\beta_2, A\beta_3) = (0, 0, 0)$；
  * 这意味着矩阵 $B$ 的**每一个列向量都是齐次方程组 $Ax = 0$ 的解**！
* **解空间维数博弈（Sylvester 秩定理）**：
  * $r(A) + r(B) \leqslant 3 \implies r(A) \leqslant 3 - r(B)$；
  * 齐次方程解空间维数 $S = 3 - r(A) \geqslant r(B)$。如果 $B$ 的独立列向量已经达到了解空间的维数，则 $B$ 的列向量直接构成基础解系，根本不需要求解 $A$！

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
* **讲义考点**：“矩阵方程 $AB=O$ 的解空间与秩性质” 联立 “齐次线性方程组基础解系与通解求法”（对接李永乐《线性代数辅导讲义》第四章线性方程组核心考点）。

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
* **4.1 显式等价公式对齐阵列**：

| 锁定类型 | 题目伪装算子 | 法理前置锁（连接桥梁） | 课本定理 / 刚性结论 |
| :--- | :--- | :--- | :--- |
| **【矩阵非零锁】** | 第一行 $(a,b,c) \neq (0,0,0)$ | 锁定矩阵 $A$ 至少存在一个非零行 | $r(A) \geqslant 1$ |
| **【秩的不等式锁】** | $AB = O$ | Sylvester 秩定理与列向量为解 | $r(A) + r(B) \leqslant 3$ |
| **【参数分流讨论锁】** | 矩阵 $B$ 第 3 列含有 $k$ | 列变换判定 $r(B)$ 是否满 2 阶 | $k \neq 9$ ($r(B)=2$) 与 $k = 9$ ($r(B)=1$) |

* **4.2 错因深度复盘（🔴 无思路破局）**：
  * 考场“无思路”的最大心理障碍就是被“未知的第二、三行”所羁绊。
  * 牢记定理：**$AB=O$ 时，$B$ 的列向量全是 $Ax=0$ 的解！** 遇到此类题，第一步绝对不是猜 $A$，而是对 $B$ 做初等变换看 $B$ 的秩与列向量！

#### 第五步：Layer 5 演算落地（最优化计算工程）
* **确立 $r(A)$ 下界**：
  由于 3 阶矩阵 $A$ 的第一行 $(a,b,c)$ 不全为零，说明 $A$ 至少有一行不为零向量，即 $A \neq O$，故：
  $$r(A) \geqslant 1$$

* **分析矩阵 $B$ 的秩**：
  对矩阵 $B$ 进行初等列变换：
  $$B = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 3 & 6 & k \end{pmatrix} \xrightarrow[c_3 - 3c_1]{c_2 - 2c_1} \begin{pmatrix} 1 & 0 & 0 \\ 2 & 0 & 0 \\ 3 & 0 & k - 9 \end{pmatrix}$$
  显然，参数 $k$ 的分界临界点为 $k = 9$。

* **分类讨论求解**：

  * **第一类：当 $k \neq 9$ 时**
    此时 $r(B) = 2$。
    根据 Sylvester 秩不等式，$AB = O \implies r(A) + r(B) \leqslant 3$：
    $$r(A) \leqslant 3 - r(B) = 3 - 2 = 1$$
    结合 $r(A) \geqslant 1$，法理上刚性锁定：
    $$r(A) = 1$$
    齐次线性方程组 $Ax = 0$ 的基础解系所含向量个数为：
    $$n - r(A) = 3 - 1 = 2$$
    由 $AB = O$ 知，$B$ 的每一列都是 $Ax = 0$ 的解。
    取 $B$ 的第 1 列 $\xi_1 = (1, 2, 3)^{\mathrm{T}}$ 与第 3 列 $\xi_2 = (3, 6, k)^{\mathrm{T}}$。
    因为当 $k \neq 9$ 时，$\xi_1$ 与 $\xi_2$ 不成比例，线性无关，故它们直接构成 $Ax = 0$ 的一个基础解系！
    此时方程组 $Ax = 0$ 的通解为：
    $$x = c_1 \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} + c_2 \begin{pmatrix} 3 \\ 6 \\ k \end{pmatrix} \quad (c_1, c_2 \text{ 为任意常数})$$

  * **第二类：当 $k = 9$ 时**
    此时 $r(B) = 1$。
    由 $r(A) + r(B) \leqslant 3$ 得 $r(A) \leqslant 2$。结合 $r(A) \geqslant 1$，得到 $r(A)$ 可能为 1 或 2，需进一步分类：

    * **子情况 2.1：若 $r(A) = 2$**
      解空间维数为 $3 - r(A) = 3 - 2 = 1$。
      $B$ 的第 1 列 $\xi_1 = (1, 2, 3)^{\mathrm{T}} \neq 0$ 是 $Ax = 0$ 的解，直接构成基础解系。通解为：
      $$x = c_1 \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} \quad (c_1 \text{ 为任意常数})$$

    * **子情况 2.2：若 $r(A) = 1$**
      解空间维数为 $3 - r(A) = 3 - 1 = 2$。
      因为 $r(A) = 1$，$A$ 的各行均与第一行 $(a,b,c)$ 成比例。
      齐次方程组 $Ax = 0$ 同解于其第一行构成的单方程：
      $$ax_1 + bx_2 + cx_3 = 0$$
      不妨设 $a \neq 0$（若 $a=0$，同理按 $b \neq 0$ 或 $c \neq 0$ 选取），移项得 $x_1 = -\frac{b}{a}x_2 - \frac{c}{a}x_3$。
      令自由未知量 $(x_2, x_3)$ 分别为 $(1, 0)$ 和 $(0, 1)$，求得基础解系为：
      $$\eta_1 = \begin{pmatrix} -\frac{b}{a} \\ 1 \\ 0 \end{pmatrix}, \quad \eta_2 = \begin{pmatrix} -\frac{c}{a} \\ 0 \\ 1 \end{pmatrix}$$
      方程组 $Ax = 0$ 的通解为：
      $$x = c_1 \begin{pmatrix} -\frac{b}{a} \\ 1 \\ 0 \end{pmatrix} + c_2 \begin{pmatrix} -\frac{c}{a} \\ 0 \\ 1 \end{pmatrix} \quad (c_1, c_2 \text{ 为任意常数})$$
      *(注：若 $a=0$ 且 $b\neq 0$，通解可由对称基底表示；若 $a=b=0$ 则 $c\neq 0$ 同理)*。

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
* **易错防线**：
  * **防线一**：在 $k=9$ 时漏掉分类讨论！很多考生只想到 $r(A)=2$ 或只想到 $r(A)=1$，未能把 $1 \leqslant r(A) \leqslant 2$ 的两种可能性全部穷尽；
  * **防线二**：在写 $r(A)=1$ 的通解时，未能利用好第一行 $(a,b,c)$，导致写不出基础解系。
* **延伸变式**：若条件改为 $BA=O$，则转置后成为 $A^{\mathrm{T}} B^{\mathrm{T}} = O$，此时 $B^{\mathrm{T}}$ 的列向量成为 $A^{\mathrm{T}} x = 0$ 的解，反映了行空间与解空间的正交补关系。

🎯 **最终正确答案**：
$$
\begin{cases}
\text{当 } k \neq 9 \text{ 时，通解为 } x = c_1 \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} + c_2 \begin{pmatrix} 3 \\ 6 \\ k \end{pmatrix} \\
\text{当 } k = 9 \text{ 且 } r(A) = 2 \text{ 时，通解为 } x = c_1 \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} \\
\text{当 } k = 9 \text{ 且 } r(A) = 1 \text{ 时，通解为 } x = c_1 \begin{pmatrix} -\frac{b}{a} \\ 1 \\ 0 \end{pmatrix} + c_2 \begin{pmatrix} -\frac{c}{a} \\ 0 \\ 1 \end{pmatrix} \quad (\text{设 } a \neq 0)
\end{cases}
$$
