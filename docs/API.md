## 1. 题解卡片 Markdown 语法契约

每道题解在 `content/*.md` 中必须满足以下固定结构：

```markdown
<a id="problem-[题号]"></a>

### 📌 题目 [题号]：[简明题目标题]
所属章节：`[标准章节名]` · 来源题集：`[来源题集名]`
题型标签：`[考点1]` / `[考点2]` / `[秒杀技巧]`

**原题呈现**：
[原题文本，公式使用 $...$ 或 $$...$$，微元加间距与正体 \, \mathrm{d}x]

> 💡 **核心突破手眼法**：
> IF**: [题干特征识别]
> THEN**: [直击秒杀切入点]

#### 第一步：Layer 1 代数表征（识别考卷符号）
[正文与公式]

#### 第二步：Layer 2 语义逻辑（直击几何/物理本质或代数同构）
[正文与公式]

#### 第三步：Layer 3 教科书目标（精准对接讲义考点）
[正文与公式]

#### 第四步：Layer 4 认知路径（【等价性是如何建立的？】法理本质与最优路径推导）
[正文与公式]

#### 第五步：Layer 5 演算落地（最优化计算工程）
[正文与公式]

#### 第六步：Layer 6 题型升维（【一题多变与陷阱防线】）
[正文与公式]

🎯 **最终正确答案**：
$$[标准最终答案]$$

[🔝 返回目录](#目录)
---
```

## 2. 大纲清单模式 (`manifest.json`)

`manifest.json` 是前端导航的核心依赖，其 JSON Schema 契约如下：

```json
{
  "updatedAt": "2026-09-17 12:00:00",
  "totalProblems": 524,
  "chapters": [
    {
      "name": "二重积分",
      "subject": "高等数学",
      "count": 48,
      "problems": [
        {
          "id": "problem-524",
          "number": "524",
          "title": "连续型对称性与极坐标微元代换",
          "source": "严选题",
          "chapter": "二重积分",
          "tags": ["极坐标变换", "对称性秒杀"],
          "file": "content/高等数学_题解集.md",
          "anchor": "problem-524"
        }
      ]
    }
  ]
}
```

## 3. 客户端 LocalStorage 数据契约

浏览器持久化采用以下统一命名空间：

| Key 键名 | 类型 | 结构说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `math_bookmarks` | Object | `{ [problemId: string]: string }` 星标状态映射 | `{"problem-524": "star", "problem-38": "redo"}` |
| `math_user_notes` | Object | `{ [problemId: string]: string }` 个人随手记备忘 | `{"problem-524": "极坐标切入时注意 r 雅可比行列式"}` |
| `math_theme` | String | 主题模式，支持 `light` / `dark` | `"dark"` |
