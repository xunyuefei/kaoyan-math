# 🔍 考研数学题解代码与排版审查规范 (Code Review Prompt)

当审查任何新提交或修改的题解 Markdown 时，请严格对照以下审查检查表（Checklist）：

---

## 审查检查表 (Review Checklist)

### 1. 题号与锚点规范
* [ ] **专题强化题**：题号是否与用户的原题题号一致？锚点格式是否为 `<a id="problem-[题号]"></a>`？
* [ ] **历年真题 (2005–2026 数二)**：
  * 锚点是否严格遵循 `<a id="problem-YYYY-NN"></a>`（例如 `<a id="problem-2021-15"></a>`、`<a id="problem-2005-4"></a>`）？
  * 标题是否格式化为 `### 📌 题目 YYYY-TNN：[简明题目标题]`？
  * 题号是否经过官方真实真题库核验（真实试卷原题号，如第 15 题 👉 `T15`），严禁使用任意自增流水号？
* [ ] 锚点在整个 `content/` 目录下是否具有全局唯一性？

### 2. 章节与大纲合规性
* [ ] 所属章节是否完全匹配 12 大标准章节之一？（严禁擅自创造如“导数应用”、“矩阵求逆”等自创章节）
* [ ] 来源题集是否合规：
  * 专题题集：`辅导讲义`、`660题`、`严选题`、`精选题`（兼容历史 `600题`）；
  * 历年真题：`[YYYY年数二]`（如 `2005年数二`、`2021年数二`）。

### 3. 历年真题四维错因归因体系 (Pain Point Checklist)
* [ ] 若为历年真题，题型标签第一项是否精准挂载四维带色痛点标签之一：
  * `🔴 无思路`（破局层断裂，未破题或方向迷茫）
  * `🟠 计算失误`（思路完全正确但执行演算、符号、通分手滑）
  * `🔵 产生疑问`（解析看懂但法理层/等价条件存疑）
  * `🟡 审题陷阱`（漏看开闭区间、单侧极限、命题人暗坑）
* [ ] 题解是否针对该错因痛点，在 Layer 4（认知路径）或 Layer 6（题型升维/陷阱防线）中给出了直击本质的复盘反思？

### 4. SOP 结构完整度
* [ ] 是否包含 `💡 核心突破手眼法`（必须具备 IF 题干特征与 THEN 秒杀切入点两个要素）？
* [ ] 是否完整包含 6 层 Layer 标题？
* [ ] **格式关键项**：所有 `#### 第X步：Layer X ...` 标题行后是否有独立的换行？（严禁同行拼接，防止前端渲染为胶囊气泡）
* [ ] 结尾是否包含 `🎯 最终正确答案`（使用 `$$ ... $$`）与 `[🔝 返回目录](#目录)`？

### 5. LaTeX 规范
* [ ] 微元符号是否加了窄空格与正体：`\, \mathrm{d}x`、`\, \mathrm{d}y`、`\, \mathrm{d}t`？
* [ ] 矩阵与行列式是否采用 `\begin{pmatrix}` 或 `\begin{vmatrix}`？
* [ ] 长公式是否有独立 `$$ ... $$` 块？
* [ ] 是否存在任何 `<span class="math-ph">` 占位符泄露？

### 6. 文件路由与物理隔离
* [ ] 高数题目是否准确追加在 `content/高等数学_题解集.md` 底部？
* [ ] 线代题目是否准确追加在 `content/线性代数_题解集.md` 底部？
* [ ] 历年真题是否准确追加在 `content/历年真题_数二.md` 底部？
* [ ] 根目录下同名文件未被污染？
* [ ] 修改后是否通过 `python tests/test_math_integrity.py` 完整性校验？
