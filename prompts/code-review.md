# 🔍 考研数学题解代码与排版审查规范 (Code Review Prompt)

当审查任何新提交或修改的题解 Markdown 时，请严格对照以下 8 项检查表（Checklist）：

---

## 审查检查表 (Review Checklist)

### 1. 题号与锚点规范
* [ ] 题号是否与用户的原题题号一致？
* [ ] 锚点格式是否为 `<a id="problem-[题号]"></a>`？
* [ ] 是否在整个 `content/` 下具有全局唯一性？

### 2. 章节与大纲合规性
* [ ] 所属章节是否完全匹配 12 大标准章节之一？（严禁擅自创造如“导数应用”、“矩阵求逆”等自创章节）
* [ ] 来源题集是否为标准题集之一（如 `严选题`、`600题`、`660题`、`辅导讲义`、`精选题`）？

### 3. SOP 结构完整度
* [ ] 是否包含 `💡 核心突破手眼法`（必须具备 IF 和 THEN 两个要素）？
* [ ] 是否完整包含 6 层 Layer 标题？
* [ ] **格式关键项**：所有 `#### 第X步：Layer X ...` 标题行后是否有独立的换行？（严禁同行拼接）
* [ ] 结尾是否包含 `🎯 最终正确答案` 与 `[🔝 返回目录](#目录)`？

### 4. LaTeX 规范
* [ ] 微元符号是否加了窄空格与正体：`\, \mathrm{d}x`？
* [ ] 矩阵是否采用 `\begin{pmatrix}` 或 `\begin{vmatrix}`？
* [ ] 长公式是否有独立 `$$ ... $$` 块？
* [ ] 是否存在任何 `<span class="math-ph">` 占位符泄露？

### 5. 文件路由
* [ ] 高数题目是否准确追加在 `content/高等数学_题解集.md` 底部？
* [ ] 线代题目是否准确追加在 `content/线性代数_题解集.md` 底部？
* [ ] 根目录下同名文件未被污染？
