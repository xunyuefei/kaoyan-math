### 4. 铁律与防线
1. **题号优先判定**：若用户输入中有原始题号（如 38.），必须优先使用；历年真题严格采用官方真实题号（如 T15）；

3. **Layer 标题独占换行**：所有 `#### 第X步：Layer X ...` 标题必须独占一行，标题后必须换行再写正文；
4. **数据源物理隔离**：高数写入 `content/高等数学_题解集.md`，线代写入 `content/线性代数_题解集.md`，真题写入 `content/历年真题_数二.md`，严禁写入根目录下同名文件；
5. **部署发布闭环**：写入文件后必须在终端执行 `npm run deploy` 自动同步 manifest 并推送到 GitHub。
